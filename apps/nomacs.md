# NOMACS

 Nomacs is a free, open source image viewer, which supports multiple platforms.

 This script allows you to choose between the Official AppImage and the unofficial one.

 SITE: https://github.com/nomacs/nomacs

 Unofficial AppImage: https://github.com/pkgforge-dev/Nomacs-AppImage
